# Contributing to Terra Incognita

Everyone can help: researchers, students, translators, curious people.

## Without GitHub
Use the form at the bottom of https://www.terraincognita.ca to propose a new question, report an error, or volunteer as a reviewer.

## With GitHub
1. Edit the file of the question in `data/questions/` (or add a new one). The format and rules are in `AGENT.md`.
2. Every claim needs a source you have read. Nothing invented.
3. Keep all seven languages in sync. If you can only write one, say so in the pull request and translators will complete it.
4. Run `python3 tools/validate.py` and open a pull request. The check must pass.

## Reviewers
Researchers who review a fiche in their field are listed on it ("Reviewed by") with their institution, unless they prefer not to be. To volunteer, use the form or open an issue with your name, institution and field.
